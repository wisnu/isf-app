## UI Flow

**ON OPEN (QProposal List):**
- BeginDate/EndDate default = today
- BranchCode auto-fill dari session
- Data tidak langsung tampil — user klik "Tampilkan Data"

**ON OPEN (fAddProposal):**
- ProposalDate, ProposalReceivedDate default = today
- ProposalNominal default = 0.0
- ProposalNo tampil "&lt;AUTOGENERATED&gt;"

**ON MUSTAHIQ SELECTED:**
- Server call `GetTotalProposal(MustahiqId)` → isi TotalProposal
- Auto-fill AddressStreet, Kelurahan, Kecamatan

**ON SAVE (fAddProposal):**
Validasi: ProductGroupId, ProposalDate, ProposalReceivedDate, ProposalDescription, ProposalNominal, MustahiqId — semua wajib diisi.

**ON DELETE:**
- Konfirmasi dialog
- CallServerMethod 'DeleteProposal'

## Save Logic

### CREATE
**Entry:** fAddProposal_data.py → Simpan()

1. Cek duplikat via ProposalNo
2. GenerateProposalNumber(ProductGroupCode, ProposalReceivedDate)
   - Format: `{ProductGroupCode}/{seq:05d}/{MM}/{YY}`
   - Sequence key: `"PROPOSAL/{ProductGroupCode}/{MM/YY}"` — per bulan per jenis program
3. Set fields: ProposalNo, ProductGroupId, ProposalDate, ProposalDescription, ProposalNominal, ProposalReceivedDate, ProposalReceivedBy, ProposalReferenceBy, ProposalReferencePosition, MustahiqId
4. `ProposalStatus = 'B'` (HARDCODED)
5. BranchCode di-set dari session

### UPDATE
**Entry:** fEditProposal_data.py → Simpan()

1. Jika bulan/tahun ProposalReceivedDate berubah ATAU ProductGroupId berubah: re-generate ProposalNo
2. Update semua field (ProposalStatus dapat diubah)

### DELETE
**Entry:** QProposal_data.py → DeleteProposal()

1. oProposal.Delete() — **TANPA CheckForDelete di legacy**
2. isf-app HARUS: tolak delete jika `proposalstatus = 'S'`

## Status Lifecycle Proposal

```
[CREATE via fAddProposal]       → proposalstatus = 'B'
       ↓
[fSelectProposal dari modul MustahiqProduct/Program]
       ↓ (hanya tampilkan status='B')
[Proposal dipilih dan di-link]  → proposalstatus = 'S'  (diubah oleh modul Program)
       ↓ (jika MustahiqProduct dihapus)
[MustahiqProduct.OnDelete()]    → proposalstatus = 'B'  (reset kembali)
```

**CATATAN:** Tidak ada workflow approval internal dalam modul Proposal. Modul Proposal = data-entry saja. Status diubah oleh modul MustahiqProduct/Program (coupling lintas modul).

**WORKFLOW TYPE: CRUD** (bukan Approval Workflow)
